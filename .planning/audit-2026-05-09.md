## P0 · Bugs funcionales y a11y bloqueantes

### P0-1 · `setPhase()` aborta el boot completo
- **Archivo**: `prototype.html:12338`
- **Síntoma**: `document.getElementById('child-name-label').textContent = ...` — elemento no existe en el DOM. `TypeError: Cannot set properties of null` se lanza.
- **Cascada**: `setPhase(selectedPhase)` se llama en el IIFE init (línea 13707) ANTES de `goTo(initial)` (13708). El throw aborta init: `renderGrowthBook`, `renderMilestoneBook`, `renderLogDetailScreen`, etc nunca corren en boot.
- **Repro**: cargar la página. Usar consola: `console.log(window.location.hash)` → boot falla silenciosamente, los libros muestran estado inicial pero no las renderizaciones JS-driven.
- **Fix**: guarda con `const lbl = document.getElementById('child-name-label'); if (lbl) lbl.textContent = ...;` o eliminar la línea (el id no se usa en ningún markup).

### P0-2 · CTAs muertas en vacuna detail
- **Archivo**: `prototype.html:11146,11148`
- **Síntoma**: `renderVaccineDoseDetail` emite `data-vaccine-mark-done="<i>"` y `data-vaccine-remind="<i>"` en los botones de acción, pero la delegación de clicks (líneas 13325–13657) no tiene branch para ellos. Tap = nada.
- **Fix**:
  ```js
  const mark = event.target.closest('[data-vaccine-mark-done]');
  if (mark) {
    vaccineSchedule[+mark.dataset.vaccineMarkDone].state = 'done';
    renderVaccineBook();
    return;
  }
  ```

### P0-3 · Sheets sin focus trap, sin `aria-modal`, sin `inert` fondo
- **Archivo**: `prototype.html:7879-7930` (markup `#sheet`, `#qlog-sheet`, `#measure-modal`, `#milestone-modal`, `#datepicker-modal`)
- **Síntoma**: cuando un sheet abre, Tab se cuela detrás del scrim → SR navega contenido que no debería ver. Esc cierra solo el sheet genérico (línea 13687); qlog/measure/milestone/datepicker quedan abiertos.
- **Fix**: añadir `aria-modal="true" role="dialog"` a cada sheet, `inert` al `.screen` activo cuando hay sheet abierto, handler `keydown=Escape` para todos los modales.

### P0-4 · Inputs decimales sin teclado correcto
- **Archivo**: `prototype.html:7901,7906,7911` (peso/talla/PC)
- **Síntoma**: `<input type="text">` no abre teclado decimal en iOS. SR lee "edit text" sin contexto.
- **Fix**: `type="number" step="0.1"` o (preservando coma local) `inputmode="decimal" pattern="[0-9.,]*"` + `aria-describedby` a la unidad.

### P0-5 · `<aside class="sheet" aria-live="polite">` duplica anuncios
- **Archivo**: `prototype.html:7879`
- **Síntoma**: SR re-lee el sheet completo en cada apertura porque `aria-live` lo trata como región dinámica.
- **Fix**: quitar `aria-live`. Usar `aria-labelledby="sheet-title" aria-describedby="sheet-copy"`.

### P0-6 · `.input-card[role="button"]` sin keyboard handler
- **Archivo**: `prototype.html:7422`
- **Síntoma**: tabbable, pero Enter/Space no dispara la apertura del datepicker. Usuario teclado queda bloqueado.
- **Fix**: convertir a `<button>` (mejor) o añadir `keydown` handler para Enter/Space.

### P0-7 · `.nav-tab.disabled` (Chat) tabbable
- **Archivo**: `prototype.html:7666,7699,7866`
- **Síntoma**: pseudo-disabled visual, pero sigue en el orden de Tab y se puede activar.
- **Fix**: atributo HTML `disabled aria-disabled="true"`.

## P1 · Consistencia DS, a11y should-fix, JS dead state

### P1-1 · 18 tokens DS no definidos en `:root`
- **Archivos**: `prototype.html:15-108` y `design/Mimo Design System v0.2.html:21-89`
- **Tokens referenciados pero no declarados**:
  - Tone-inks: `--coral-ink`, `--mint-ink`, `--gold-ink`, `--blush-ink`
  - Tone-deeps: `--coral-deep`, `--mint-deep`, `--blush-deep`
  - Fonts: `--font-display`, `--font-text`, `--font-mono`
  - Letter-spacing: `--ls-tight`, `--ls-snug`, `--ls-eyebrow`, `--ls-meta`
  - Shadows: `--shadow-card`, `--shadow-sheet`, `--shadow-fab`
  - Device: `--device-bezel`
- **Impacto**: cualquier rule que use `var(--coral-ink)` o `var(--font-display)` evalúa a `unset` o fallback CSS por defecto. Bloquea cualquier limpieza de hex / font literals posterior.
- **Fix**: añadir bloque token a ambos `:root`:
  ```css
  --coral-ink:  #8E4A22;  --coral-deep:  #4A2510;
  --mint-ink:   #4F6647;  --mint-deep:   #2F4029;
  --gold-ink:   #6E5A2A;  --gold-deep:   #6E5A2A;
  --blush-ink:  #7A4A3A;  --blush-deep:  #6B3D2A;
  --font-display: "Lenia", "Helvetica Neue", system-ui, sans-serif;
  --font-text:    "Helvena", "Helvetica Neue", system-ui, sans-serif;
  --font-mono:    "JetBrains Mono", "SF Mono", monospace;
  --ls-tight:   -0.015em;
  --ls-snug:    -0.01em;
  --ls-eyebrow:  0.18em;
  --ls-meta:     0.04em;
  --shadow-card:  0 14px 36px rgba(42,33,27,0.10);
  --shadow-sheet: 0 26px 80px rgba(42,33,27,0.22);
  --shadow-fab:   0 6px 18px rgba(42,33,27,0.28);
  --device-bezel: #161616;
  ```
