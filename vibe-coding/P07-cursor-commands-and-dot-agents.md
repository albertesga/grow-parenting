# P07 — Cursor commands, `.cursor/README`, optional `.agents/`

## Role

Add Cursor slash-command stubs (not generated by `sync-agents.sh`) and optional **`.agents/skills/**` mirrors — matching how [latitude-dev/latitude-llm](https://github.com/latitude-dev/latitude-llm) exposes **`.agents/skills`** alongside **`.cursor`**.

## Preconditions

- `npm run agents:sync` has run (P06).

## Postconditions

- `.cursor/README.md` documents sync, rules, and `/opsx-*` commands (same structure as [multi-repo P07](../multi-repo/P07-cursor-commands-and-dot-agents.md)).
- `.cursor/commands/opsx-{propose,explore,apply,archive}.md` point to `.agent/skills/openspec/*.md`.
- Optional: `.agents/skills/{propose,apply,archive,explore,profiles}/SKILL.md` with `@../../../.agent/skills/openspec/<id>.md` (or equivalent depth).

## Latitude-style note

If the repo already contains **`.agents/skills`**, merge rather than duplicate names: keep a **single canonical** skill body under `.agent/skills/openspec/` and let `.agents/skills/*/SKILL.md` stay thin `@` stubs (same pattern as `.claude/skills/`).

## Commands

Copy command file patterns from [multi-repo P07](../multi-repo/P07-cursor-commands-and-dot-agents.md); replace `{{META_WORKSPACE_NAME}}`.

## Check

- `/opsx-propose` (etc.) resolves in Cursor and each command references an existing `.agent/skills/openspec/*.md` file.
