# Rediseño Real De Gráficas De Desarrollo · OMS DS

## Summary
- Cambiar el approach de Desarrollo: dejar de renderizar 3 gráficas apiladas grandes y pasar a un único componente `OMS curve` estilo design system con tabs `Peso · Talla · PC`.
- La gráfica activa ocupa todo el espacio visual, con histórico y CTA debajo solo para la métrica seleccionada.
- Mantener datos mock, percentiles mock, log central, guardado de medidas e interacción por punto/histórico.

## Key Changes
- Sustituir `growth-curve-card` apiladas por un módulo único `growth-oms-card` basado en `design/Grow Product Components v0.1.html · § C — OMS curve`.
- Añadir estado `growthActiveMetric = 'weight'` y tabs internas:
  - `Peso`, `Talla`, `PC`.
  - `PC` se oculta si edad `>36m`.
- Rehacer CSS para usar el lenguaje DS:
  - `.oms-card`, `.oms-head`, `.oms-tabs`, `.oms-chart`, `.oms-legend`, `.oms-stats`.
  - Chart con `viewBox="0 0 600 280"` y `preserveAspectRatio="none"` como el DS, no el SVG alto actual.
  - Fondo `paper-soft`, banda P3-P97 tenue, P50 dashed, path del peque coral/ink fuerte, marcador seleccionado coral.
- Rehacer `renderGrowthChart()` para ser DS-derived:
  - márgenes DS: plot `40–580 x 40–220`.
  - labels y ejes más compactos.
  - tooltip pequeño integrado tipo DS, no pill enorme flotante.
  - puntos clicables con hit area invisible.
- Cambiar histórico:
  - mostrar solo las últimas 4 medidas de la métrica activa.
  - tap en fila selecciona punto.
  - fila seleccionada queda con fondo blush suave.
- Cambiar guardado:
  - al guardar desde `log-registro` una medida, seleccionar automáticamente la métrica rellenada más relevante.
  - si se guardan varias, quedarse en la tab de la métrica desde la que se abrió el log o `Peso` por defecto.

## Implementation Details
- Editar solo `prototype.html`.
- Mantener `growthMeasurements`, `growthMetricConfig`, `getMetricPercentile()`, `saveMeasureFromLog()` y `data-log-type="medida"`.
- Añadir helpers:
  - `setGrowthActiveMetric(metricId)`.
  - `renderGrowthMetricTabs()`.
  - `renderGrowthOmsCard()`.
  - `renderGrowthStats(metric, measurements, selectedIndex)`.
- Eliminar del render principal las 3 cards apiladas; `renderGrowthBook()` debe renderizar cover + toggle edad + una sola `growth-oms-card`.
- Mantener compatibilidad de eventos:
  - `[data-growth-point]` sigue seleccionando punto.
  - nuevo `[data-growth-metric-tab]` cambia tab.
  - `[data-log-type="medida"]` abre la pantalla central de log.
