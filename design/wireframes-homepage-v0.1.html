Embarazo

1 · Concepto

La homepage es una columna editorial larga de 13 bloques + header global + footer. Cada bloque cumple una promesa del manifesto. El bloque protagonista (visualmente más grande) es 5 · Los libros. La parallax del avatar 3 fases (coral → blush → mint) acompaña el scroll y conecta visualmente las etapas del journey de 1.000 días.

2 · Parallax avatar 3 fases · cómo funciona

A medida que el usuari@ hace scroll, un avatar fijo en una columna lateral (desktop) o pequeño tracker top-right (mobile) cambia entre las 3 fases con crossfade: coral (embarazo) en bloques 0-3 · blush (bebé) en bloques 4-7 · mint (toddler) en bloques 8-13. La progresión visualiza el journey de 1.000 días sin que el usuario tenga que leerlo.

5 · Implementación técnica · parallax avatar 3 fases

5.1 · CSS scroll-driven (canon · Chrome 115+, Firefox 130+)

/* Parallax avatar 3 fases · canon DS v0.3 */
@supports (animation-timeline: scroll()) {
  .parallax-avatar .avatar.coral {
    animation: phase-coral linear;
    animation-timeline: scroll(root);
    animation-range: 0% 33%;
  }
  .parallax-avatar .avatar.blush {
    animation: phase-blush linear;
    animation-timeline: scroll(root);
    animation-range: 25% 66%;
  }
  .parallax-avatar .avatar.mint {
    animation: phase-mint linear;
    animation-timeline: scroll(root);
    animation-range: 58% 100%;
  }
  @keyframes phase-coral {
    0% { opacity: 1; transform: scale(1); }
    100% { opacity: 0; transform: scale(0.92) translateY(-12px); }
  }
  @keyframes phase-blush {
    0% { opacity: 0; transform: scale(0.92) translateY(12px); }
    50% { opacity: 1; transform: scale(1); }
    100% { opacity: 0; transform: scale(0.92) translateY(-12px); }
  }
  @keyframes phase-mint {
    0% { opacity: 0; transform: scale(0.92) translateY(12px); }
    100% { opacity: 1; transform: scale(1); }
  }
}
@media (prefers-reduced-motion: reduce) {
  .parallax-avatar .avatar { transition: none; }
  /* solo crossfade simple por bloque, sin escalado */
}

5.2 · JS fallback con IntersectionObserver (Safari · navegadores antiguos)

// Fallback canon DS v0.3
const PHASES = [
  { id: 'coral', threshold: 0,    label: 'Embarazo' },
  { id: 'blush', threshold: 0.35, label: 'Bebé' },
  { id: 'mint',  threshold: 0.65, label: 'Crianza' }
];
const avatars = document.querySelectorAll('.parallax-avatar .avatar');
const tracker = document.getElementById('tracker-dot');
const label   = document.getElementById('tracker-label');

function updatePhase() {
  const progress = window.scrollY / (document.body.scrollHeight - window.innerHeight);
  const phase = [...PHASES].reverse().find(p => progress >= p.threshold);
  avatars.forEach(a => a.classList.toggle('show', a.dataset.phase === phase.id));
  tracker.className = 'dot ' + phase.id;
  label.textContent = phase.label;
}
window.addEventListener('scroll', updatePhase, { passive: true });
updatePhase();
