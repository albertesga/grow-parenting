§ B — Iconography

One <symbol> set, every icon by reference.

Todos los SVGs duplicados en la app se sirven desde un único <svg><defs> al inicio del body, con stroke-width 1.5–1.85 según contexto. Color via currentColor en CSS; nunca hard-coded en el path.

§ G2 — Quick log grid

One sheet, every type of log.

Aparece al pulsar el FAB del bottom nav. Tres columnas, aspect-ratio 1/1. Cada tile lleva icono + label en negrita + sub en gris muted. Tonos opcionales (mint para tomas/sueño, gold para vacuna/temperatura, coral para síntoma/alimento).

Tile grid

.qlog-grid · .qlog-tile + tone

El label y sub son siblings dentro de un mismo span: el label es display: block (no inline) — patrón importante para que no aparezcan pegados ("Tomatimer o sello"). Tile lleva overflow: hidden y min-width: 0 para no desbordar.

Bottom sheet for quick log, measure, milestone.

Hoja inferior con grabber arriba, head con título y meta, contexto opcional, y el contenido. Border-radius grande (26 px), shadow inverso al norte para sugerir elevación desde abajo.

§ I — Accessibility

Keyboard-only focus, aria-labels, tap targets ≥ 36 px.

Toda la app pasa :focus-visible con outline coral 2 px. Ningún outline: 0 sin compensación. IconButtons exigen aria-label. Mínimo de altura interactiva en --tap-target-min: 36px.

Focus ring · keyboard navigation

:focus-visible · 2 px coral

Hace Tab sobre los botones de esta página: cada uno muestra un anillo coral. Mouse no lo ve (:focus sin -visible tiene outline: 0).

Aria-label patterns

icon-only buttons

Botones con SVG y sin texto visible llevan etiqueta accesible:

  • .book-back y .book-close-pill → aria-label="Cerrar libro"
  • .log-register-back → aria-label="Cerrar ${'{'}returnLabel${'}'}"
  • .fab → aria-label="Abrir registro rápido"
  • .yo-btn → aria-label="Añadir hito"
§ J — v0.2 changelog

What changed since v0.1.

Resumen de las decisiones que esta versión documenta. Cada bullet se aplicó primero en prototype.html; este DS las formaliza.

Highlights

  • TINTED CTAS canon · primary actions usan coral por defecto, ink reservado para casos puntuales (FAB, IconButton X).
  • IconButton round · 36/44/52 px. El X arriba a la derecha es el patrón único de cerrar libros y log register screens.
  • FREE sticker pattern · paper bg, sin borde, sin sombra, rotación −6°, font 600. Reemplaza la versión bordeada anterior.
  • Tilted filter chips · cada chip de la fila Hoy lleva una rotación distinta (−3°, +2°, −2°, +3°…) para evitar la rigidez visual.
  • Module consolidation · .module-action, .module-pill, .module-chip reemplazan ~5 duplicados por módulo (food/sleep/lactation/pregnancy/vaccine).
  • Icon registry · 14 <symbol> al inicio del body. 29 SVGs inline reemplazados por <use>.
  • Tokens · --fs-* (10 niveles), --space-* (6 niveles), --tap-target-min.
  • :focus-visible globally · outline coral 2 px solo para teclado, mouse no ve cambios.
  • Log-choice fix · radio input correctamente oculto (1×1 px) para que no herede width 100% del rule genérico.
  • Segmented selector · gradient base→strong sustituido por flat tonal fill (matches sticker palette).
  • OMS curve · paper-soft bg plano, preserveAspectRatio: xMidYMid meet, aspect-ratio 600/280.

Single source of truth · este archivo describe el estado actual de prototype.html. Cualquier divergencia en pantallas reales se considera un bug a corregir contra este DS.

Archivos v0.1 (Foundations · Primitives · Components · Flows) quedan en el repo como histórico de decisiones; no se sincronizan.
