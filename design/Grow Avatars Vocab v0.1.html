Four states · the whole emotional range

calm
default · 95% of usage

Eyes-forward, soft smile. The base state for every screen that isn't doing something special.

alert-soft
attention · never alarm

Same face. The signal lives in the surrounding card: 1.5px dashed border, an icon, a textual tag. Color is the last cue.

celebration-quiet
milestone · gentle 600 ms

A soft warm glow rises from above. No confetti, no shake. The character does not change — only the light around it.

night
modo 3am · 22:00 → 06:00

Dark surface, a faint top-down warm light. Reads quietly at 03:14 without waking the room.

§ E — Decisions

Two small things to confirm before Session 03.

Session 03 builds primitives (Button · Input · Card · Modal/Sheet · Bottom Nav · Phone frame). These two questions affect how those primitives are drawn.
Decision · 04 · Tinted-room boxes

Adopt the colored-box pattern as a primary section template?

Like the boxes you see throughout this page — a tinted background (coral/blush/mint/gold subtle) with a 1px tinted border, holding a heading + body + occasional sticker. This becomes the ScreenSection / LandingSection. Default proceed if you say go.

Decision · 05 · Avatar at sm/xs

The 3D render or a 2D simplified silhouette for sizes ≤ 60 px?

The current page uses the same 3D PNG for every size — at xs 36 it gets soft-edged. For Session 03 I can vectorize a flat 2D silhouette derived from each character (single fill, no shading) so list rows and chips stay crisp. Recommended.
